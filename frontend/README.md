# NeroEd frontend

The Next.js 15 study workspace for NeroEd. See the [project README](../README.md) for setup, architecture and tests.

```bash
npm install
npm run dev      # http://localhost:3000, expects the backend on http://localhost:8000
npm run lint
npm run build
```

Set `NEXT_PUBLIC_API_URL` in `.env.local` to use a different backend URL.
